# ctx for opencode

An opencode plugin. In opencode 2 it hooks the tool domain's `execute.before` for the `shell` tool (`id` and `setup`); in opencode 1 its `server()` handles `tool.execute.before` for `bash`. Either way it hands the command to `ctx hook opencode`, which rewrites it into `ctx run in "OpenCode <session>" '<command>'` in a tab named for the session, and the plugin replaces the call's command. The call's `workdir` (or the session's folder) is honoured with a `cd`, `background` calls become `… without waiting`, and a `timeout` becomes `within`. If ctx isn't reachable, the command runs as it would have.

`ctx install hooks for opencode` links this folder (as ctx wrote it, naming its `ctx`) into `~/.config/opencode/plugins/ctx`, where opencode finds plugins by itself; `ctx install hooks for opencode at <folder>` links it into that project's `.opencode/plugins/ctx`. `ctx remove hooks for opencode` removes the link. (opencode 2's `opencode plugin add` takes only npm and Git packages.)
