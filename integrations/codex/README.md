# ctx for the OpenAI Codex CLI

- `config.toml`: registers `ctx mcp` as an MCP server.
- `ctx install instructions for codex` writes the instruction block to `~/.codex/AGENTS.md`.

Turning off Codex's built-in shell is version-specific and is verified when this integration is
evaluated (SPEC.md, "Replacing agents' built-in tools"). Not on by default until `evals/agents`
passes the bar.
