# ctx for Google Gemini CLI and Antigravity

An extension: `gemini-extension.json` registers `ctx mcp` (one `shell` tool, see the main README), excludes Gemini's own shell tool, and
loads `GEMINI.md` (write it with `ctx install instructions for gemini`, or copy the block).
Install by copying this folder to `~/.gemini/extensions/ctx/`. Not on by default until
`evals/agents` passes the bar.
